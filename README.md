# Telly InTech – Site web vitrine

## Présentation

Telly InTech est une agence spécialisée dans la transformation digitale. Ce projet consiste à développer un site web vitrine moderne, performant et responsive afin de présenter les services de l’entreprise, valoriser ses réalisations et générer des demandes de devis.

L’objectif est de créer une expérience utilisateur premium inspirée des meilleures agences digitales internationales, tout en respectant l’identité visuelle de Telly InTech.

## Objectifs du projet

* Présenter les services de Telly InTech
* Renforcer la crédibilité de la marque
* Générer des leads qualifiés
* Mettre en avant les réalisations
* Optimiser le référencement naturel (SEO)
* Offrir une expérience utilisateur fluide sur tous les appareils

## Installation

### Cloner le projet

git clone https://github.com/votre-repository/telly-intech.git

### Accéder au dossier

cd telly-intech

### Installer les dépendances

npm install

### Lancer le serveur de développement

npm run dev

L’application sera disponible sur :

http://localhost:5173

## Scripts disponibles

npm run dev       # Développement
npm run build     # Build production
npm run preview   # Prévisualisation
npm run lint      # Vérification ESLint
